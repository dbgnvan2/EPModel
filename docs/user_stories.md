Functional Requirements and Use Cases

# User Stories: Societal Inflammatory Simulator

- **Anxiety Bomb Induction:** As a Logic Auditor, I want to trigger localized stress shocks (Anxiety Bombs) in specific quadrants to observe how the **Togetherness Force (TX)** propagates and whether it triggers a "Collective Demand" on the resource pool.
- **Damping Law Validation:** As a Researcher, I want to verify that units with high **Individuality (C)** successfully buffer incoming **Echo Contagion**, remaining stable while surrounding low-C units collapse into reactive modes.
- **Resource Redistribution:** As a Systems Analyst, I want to toggle a "Social Safety Net" via taxation logic to determine if active resource redistribution prevents the formation of "Necrotic Clusters" (units where M <= 0).
- **Geopolitical Border Stress:** As a Developer, I want to simulate border friction to test if a stable, highly differentiated "nation" can resist the emotional contagion bleeding over from a high-anxiety neighbor.
- **Massive Scale Visualization:** As a User, I want to scale the population from 1,000 to 100,000 units in real-time, observing "Anxiety Storms" as heat maps without the frame rate dropping below 30 FPS.
