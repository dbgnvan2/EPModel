Anxiety and functioning, week by week

Each person's anxiety and functional level at the end of every week of the run whose trace sits beside this file. Both are on the model's 0–100 scale; anxiety can run past 100. Hover or tap a panel to read the same week for everyone; arrow keys step a focused panel (shift for four weeks).

What this is. Output of a simulation that runs one theory's stated mechanisms over an invented family. It is a consistency engine for that theory — if Bowen's account is right, what follows for a family shaped like this? — not a measurement, not a prediction, and not a "virtual family" in the predictive sense (spec M11.F.10). It does not concern any real family or person, and nothing here is advice (M11.F.9). Every number in it comes from invented constants ([I]); only differences between two runs that share them carry meaning (M0.4). This run is not scripted: each person's outcome is selected by the policy, and the automatic channel learns from felt relief (Phase C).
